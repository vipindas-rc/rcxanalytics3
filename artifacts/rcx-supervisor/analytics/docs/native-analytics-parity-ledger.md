## Required native test adaptation rules

1. Do not delete or weaken Task 8 assertions. Convert only iframe/frame selectors and legacy bridge expectations that are intentionally superseded by a native route.
2. Keep fixture-intercepted UI tests distinct from the real isolated database/gateway suite. A mock workspace cannot prove persistence or gateway behavior.
3. Create/update native browser tests only after the main agent coordinates the integrated stable host. They must use a disposable database and deterministic provider seam, never the running normal database.
4. Report each row as passed, failed, blocked, or skipped with the command/environment. A missing service, host, or test DB is blocked—not a pass.
